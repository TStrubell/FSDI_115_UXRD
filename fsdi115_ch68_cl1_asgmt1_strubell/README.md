## 📖 PROJECT OVERVIEW

Strubell Goods & Gear (SGnG) is a premium handmade leather goods brand specializing in wallets, belts, keychains, travel bags, and other artisan-crafted accessories. The goal of this project is to develop a responsive e-commerce platform that emphasizes craftsmanship, quality, usability, and a seamless shopping experience across devices.

## 🎯 ASSIGNMENT OBJECTIVE
 
The purpose of this assignment is to:
1. Conduct a UX Competitive Analysis.
2. Evaluate competing e-commerce platforms.
3. Identify usability strengths and weaknesses.
4. Extract best practices for implementation in SGnG.
5. Apply UX research principles to future design decisions.

---
 
## 🔍 COMPETITORS ANALYZED
 
### 👜 Bellroy
- Clean user interface
- Excellent navigation
- Strong mobile responsiveness

### 🎒 Saddleback Leather
- Compelling craftsmanship storytelling
- Detailed product descriptions
- Strong credibility and trust factors
 
### 🧰 Huckberry
- Modern product discovery experience
- Effective categorization
- Lifestyle-focused branding

## 🚀 Planned SGnG Features

## ✅ Conclusion
The competitive analysis identified several UX patterns that can improve customer engagement, navigation efficiency, and conversion rates. Bellroy's clean design, Saddleback Leather's storytelling, and Huckberry's product discovery strategies provide valuable inspiration for SGnG's future development.
