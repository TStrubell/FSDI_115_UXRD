# Section 4 – User Flow

The SGnG user flow was designed to provide a simple path from product discovery to purchase confirmation.

User Flow:

Home → Catalog → Product Details → Cart → Confirmation

---

# Section 5 – Wireframes

Wireframes were created for:

1. Home Screen
2. Catalog Screen
3. Product Details Screen
4. Cart Screen
5. Confirmation Screen

The purpose of these wireframes is to establish layout, navigation, and content hierarchy before visual design begins.

# Section 7 – Usability Testing

Participant tested:

- Product browsing
- Viewing product details
- Adding items to cart
- Completing checkout

Results:

Easy:
- Navigation
- Product discovery

Confusing:
- Filter visibility

Improvements:
- Stronger filter controls
- More prominent cart icon
