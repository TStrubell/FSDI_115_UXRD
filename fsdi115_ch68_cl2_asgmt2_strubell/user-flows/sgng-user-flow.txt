-----------------------------------------------------
DECISION NODES
-----------------------------------------------------
DP1 @ Home:
  Choice A → Nav "Shop" → Catalog
  Choice B → Featured Product card → Product Detail (skip Catalog)
  Choice C → Category card → Catalog (filtered)

DP2 @ Catalog:
  Choice A → "Details" → Product Detail
  Choice B → "Add to Cart" → Cart (skip detail)
  Choice C → Back nav → Home

DP3 @ Cart:
  Choice A → "Proceed to Checkout" → Confirmation (happy path)
  Choice B → "Continue Shopping" → Catalog
  Choice C → Remove item(s) → Empty cart state
