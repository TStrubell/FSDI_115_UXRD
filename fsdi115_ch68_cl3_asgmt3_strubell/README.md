## Project Overview

This project is a responsive e‑commerce landing page and catalog for **Strubell Goods & Gear**, featuring:
- Semantic HTML
- CSS styling
- Flexbox layout
- Media queries for desktop and mobile
- Dark/Light mode toggle
- Simple cart using `localStorage`
